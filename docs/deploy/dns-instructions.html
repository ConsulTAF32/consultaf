DNS setup — point consultaf.org to the new website while keeping Google Workspace email working

What this is. The ConsulTAF website is now built and hosted on Netlify (live at consultaf.netlify.app). To make it appear at your own address consultaf.org, two small DNS records need to be changed where the domain is managed. Your email is not affected — the website and the email use completely different record types, and we only touch the website ones.

Where to do this — your domain is at Squarespace

consultaf.org was originally a Google Domains registration. Google sold Google Domains to Squarespace, so the domain and its DNS settings now live in the Squarespace domains dashboard — not in the Google Workspace admin console, and not at any web host.

  1. Go to https://domains.squarespace.com and sign in (use the Google account that has owned the domain — it will sign you into Squarespace).
  2. Open consultaf.org.
  3. Click DNS → DNS Settings (sometimes shown as “Manage DNS records”).
  4. Scroll to the Custom Records section — that is where the changes below are made.

1. Website records — set these website

You will replace the records that currently point the domain at Squarespace’s own pages with the two Netlify records below.

1a. The root domain (consultaf.org)

  • Delete any existing A records on the host @ (there may be four of them, with values starting 198.x — those point at Squarespace).
  • Add one new record:
TypeHostValue / Points toTTL
A@75.2.60.5Auto / 3600

1b. The www address (www.consultaf.org)

  • Delete / edit the existing www record (it currently points to ext-sq.squarespace.com).
  • Set it to this:
TypeHostValue / Points toTTL
CNAMEwwwconsultaf.netlify.appAuto / 3600
If Squarespace won’t let you put an A record on the root, use an ALIAS / ANAME record on @ pointing to apex-loadbalancer.netlify.com instead. (Same result — only use this if the plain A isn’t accepted.)

2. Records to LEAVE UNTOUCHED do not change

Important: Do not delete or modify any of the records below. These keep @consultaf.org email (Google Workspace) working. Changing them can break email delivery.
  • MX record — smtp.google.com (and/or the older ASPMX.L.GOOGLE.COM set) — keep as-is.
  • TXT — SPF (looks like v=spf1 include:_spf.google.com ~all) — keep as-is.
  • TXT — DKIM (a google._domainkey… record, if present) — keep as-is.
  • TXT — DMARC (a _dmarc record, if present) — keep as-is.
  • Any Google site-verification TXT record — keep as-is.

3. Do NOT change the nameservers

Please keep the domain’s current nameservers (the ns-cloud-…googledomains.com ones). We are not moving DNS hosting — only changing the two website records above. Switching nameservers would require rebuilding the email records and risks email downtime.

4. After the records are saved

  1. DNS changes can take from a few minutes up to 24–48 hours to take effect.
  2. Netlify will automatically issue a free HTTPS/SSL certificate once it sees the records — no action needed. (On the Netlify side the domain currently shows “Pending DNS verification”; that clears by itself once the records propagate.)
  3. The site will then load at both https://consultaf.org and https://www.consultaf.org.
Summary: at domains.squarespace.com → consultaf.org → DNS → Custom Records: set A @ → 75.2.60.5 and CNAME www → consultaf.netlify.app (replacing the old Squarespace ones). Leave every email (MX/TXT) record and the nameservers exactly as they are. That’s it. ✅
