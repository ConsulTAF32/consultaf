DNS setup — point the domain to the new website while keeping Google Workspace email working

What this is. The ConsulTAF website is hosted on Netlify. To make it appear at consultaf.org, two DNS records need to be added at wherever the domain’s DNS is managed (e.g. Squarespace / former Google Domains, or your registrar). Email is not affected — the website and the email use different record types.

Before you start — one value to fill in

The Netlify site address is needed for the www record. It looks like your-site-name.netlify.app and can be found in Netlify under Site configuration → Domain management. Replace the placeholder below with that exact value.

1. Records to ADD website

Add these two records. If a conflicting record of the same name/type already exists, update it to match.

TypeName / HostValue / Points toTTL
A@ (the root domain, consultaf.org)75.2.60.5Auto / 3600
CNAMEwwwyour-site-name.netlify.appAuto / 3600
If your DNS provider won’t allow an A record at the root, use an ALIAS / ANAME record on @ pointing to apex-loadbalancer.netlify.com instead. (Both approaches achieve the same result.)

2. Records to LEAVE UNTOUCHED do not change

Important: Do not delete or modify any of the records below. These keep @consultaf.org email (Google Workspace) working. Changing them can break email delivery.
  • MX records (e.g. smtp.google.com, or the older ASPMX.L.GOOGLE.COM set) — keep as-is.
  • TXT — SPF (looks like v=spf1 include:_spf.google.com ~all) — keep as-is.
  • TXT — DKIM (a google._domainkey… record, if present) — keep as-is.
  • TXT — DMARC (a _dmarc record, if present) — keep as-is.
  • Any Google site-verification TXT record — keep as-is.

3. Do NOT change the nameservers

Please keep the domain’s current nameservers. We are not moving DNS hosting — only adding the two website records above. Switching nameservers would require rebuilding the email records and risks email downtime.

4. After the records are saved

  1. DNS changes can take from a few minutes up to 48 hours to propagate.
  2. Netlify will automatically issue a free HTTPS/SSL certificate once it detects the records — no action needed.
  3. The site will then load at both https://consultaf.org and https://www.consultaf.org.
Summary: add A → 75.2.60.5 on the root and CNAME → your Netlify address on www. Leave every email (MX/TXT) record and the nameservers exactly as they are. That’s it. ✅
